# GTU BE Computer Question Papers Archive

A permanent index of Gujarat Technological University (GTU) Bachelor of Engineering, Computer Engineering (branch 07) old question papers: every subject code from the GTU syllabus archive, checked against every exam session on the official GTU paper server from Summer 2013 to Summer 2026.

**1437 papers found** for 151 of 176 subjects. Papers were checked on www.gtu.ac.in using the official archive pattern api/v1/question-papers/archive/file/{session}/BE/{code}.pdf; a paper counts only when the server returned a real PDF. Papers were found for sessions from Winter 2017 to Summer 2026; no papers were returned for earlier sessions.
